# Polaris

Виджеты для рабочего стола Windows 11 в стиле macOS: календарь, задачи и заметка, папки, помодоро, карта продуктивности и погода.

Задачи, заметка, календарь и журнал помодоро работают с хранилищем Obsidian через обычные `.md`-файлы. Интерфейс на английском и русском.

## Запуск

### Готовая сборка

1. Откройте вкладку [Releases](https://github.com/kobold427/polaris/releases) и скачайте `Polaris-1.0.0-portable.exe`. Он запускается без установки. Если нужен установщик, возьмите `Polaris-Setup-1.0.0.exe`.
2. Запустите файл. Он не подписан, поэтому SmartScreen может предупредить о неизвестном издателе. Нажмите «Подробнее», затем «Выполнить в любом случае».
3. Виджеты появятся на рабочем столе, а значок Polaris окажется в области уведомлений (возможно, за стрелкой «Показать скрытые значки»). По правому клику на нём открывается меню: настройки, список виджетов, подключение Obsidian, выход.

### Из исходников

Нужны Windows 11 и [Node.js](https://nodejs.org) 20.14 или новее (npm ставится вместе с ним). Git по желанию.

1. Откройте PowerShell или командную строку и проверьте Node.js:

   ```
   node -v
   ```

   Версия должна быть не ниже v20.14.

2. Скачайте проект.

   С git:

   ```
   git clone https://github.com/kobold427/polaris.git
   cd polaris
   ```

   Без git: на странице репозитория нажмите Code, затем Download ZIP и распакуйте архив. Откройте распакованную папку в Проводнике, впишите в адресную строку `cmd` и нажмите Enter. Командная строка откроется сразу в этой папке.

3. Установите зависимости и запустите:

   ```
   npm install
   npm start
   ```

   Первый `npm install` скачивает Electron и может идти несколько минут. В следующий раз достаточно одного `npm start`.

Остановить приложение можно через Ctrl+C в терминале или пункт Quit в меню значка в трее. Чтобы у каждого окна открылись DevTools, запускайте `npm start -- --dev`.

## Подключение Obsidian

Правый клик по значку в трее, затем Obsidian. Если хранилище найдено автоматически, оно будет в списке. Иначе выберите «Choose Vault Folder…» и укажите папку с хранилищем. Пока Obsidian не подключён, задачи и заметка хранятся локально, а при подключении переносятся в хранилище.

## Сборка

```
npm run dist
```

В папке `dist` появятся установщик и portable-версия. Собирать нужно на Windows.

Релиз собирается сам, когда в репозитории появляется тег вида `v1.0.0`.
